# Judging matrix

| Rubric | Score-5 target | Unspool evidence | Demo proof |
|---|---|---|---|
| Mental health — Domain Effectiveness | Directly and deeply addresses a critical pain point | Body-first interaction for moments when language and executive function are scarce; one action rather than a menu | Complete the bounded check-in and guided step |
| Mental health — Feasibility & Safety | Strong guardrails and real-world integration readiness | Crisis bypass, evidence ledger, contraindications, Django/PostgreSQL lifecycle, expiration, deletion, and explicit pre-clinical boundary | Trigger crisis bypass; show backend health and Response Map |
| AI/ML — Technical Complexity | Advanced, problem-aligned architecture with rigorous evaluation | Five-stage retrieval/ranking pipeline, 25-feature LinUCB, personal policy, global challengers, durable worker, model registry, 12,288/3,072 simulation | Open decision trace; run Model Room live |
| AI/ML — Data Safety & Responsibility | Verification, explainability, protected data, adversarial defense | Hard constraints before ML, explicit consent, hashed anonymous credential, bounded inputs, idempotency, retention, zero-violation promotion gate | Inflate excluded-arm test; show Data & Control and promotion report |
| Innovation & Novelty | A fresh way to address the problem | Learns which bounded nonverbal action fits without simulating a therapist | Show body signals → one action → explicit outcome → adaptation |
| UI/UX & Accessibility | Stunning, frictionless, broadly accessible | Low-stimulation visual system, guided keyboard flow, screen-reader semantics, reduced motion, high contrast, mobile reflow | Keyboard-run the check-in and guided mode at 360px |

## Claims discipline

Do not say “clinically validated,” “treats anxiety,” “prevents crisis,” “proves efficacy,” “HIPAA compliant,” or “the model knows how the user feels.” Say “pre-clinical,” “literature-informed,” “bounded support option,” “explicit outcome,” “synthetic engineering evaluation,” and “designed for clinician review.”
