# Judging matrix

This matrix maps the Summer 2026 rubric's score-5 language to observable evidence in Unspool.

| Rubric | Score-5 target | Unspool evidence | Demo proof |
|---|---|---|---|
| Mental health - Domain Effectiveness | Directly and deeply addresses critical pain points in an optimal, unique way | Solves the language/executive-function gap during overwhelm; body-first signals; one-step output; bridge back to humans | Complete the two-minute check-in and copy the bridge message |
| Mental health - Feasibility & Safety | Effective safety guardrails, clinical validity, prepared for real-world integration | Crisis bypass, bounded practice library, cautions, opt-outs, no diagnosis, tests, explicit pre-clinical limitation | Open crisis bypass and show passing safety tests |
| AI/ML - Technical Complexity | Complex multi-stage pipeline or innovative architecture aligned to the problem | Hybrid retrieval, hashed local embeddings, hard constraints, contextual bandit, explanations, exact local audit | Open “Why this step”; run the 3,072-case audit |
| AI/ML - Data Safety & Responsibility | Hallucination defense, adversarial defense, explainability, protected sensitive data, bias mitigation | No generative medical output, bounded inputs, no free text, fail-closed checks, access-parity tests, explicit local outcomes, synthetic in-memory audits | My Pattern + How It Works + local synthetic audit |
| Innovation & Novelty | Disruptive new approach to the problem | Begins below language and uses AI to subtract choices rather than simulate a therapist | Hero, body-signal flow, single recommendation |
| UI/UX & Accessibility | Stunning, frictionless, universally accessible | Responsive custom UI, semantic dialogs, focus states, keyboard controls, high-contrast and reduced-motion support, access needs in core flow | Keyboard-run the check-in; resize to mobile |

## Claims discipline

Do not say “clinically validated,” “treats anxiety,” “prevents crisis,” or “HIPAA compliant.” Say “evidence-informed,” “pre-clinical,” “self-regulation option,” “privacy-first,” and “designed for clinician review.” This strengthens rather than weakens the safety score.
